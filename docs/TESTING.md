# HSU PLUS 사용 테스트 안내 (친구용, 0.3.1)

> 학생이 만든 프로토타입이에요. 학교 공식 서비스가 아니에요.
> 학교 사이트는 **읽기만** 하고, 신청·제출은 하지 않아요. 비밀번호를 저장하지 않고, 성적·연락처는 읽지 않아요.

## 1. 설치 (5분)
1. 받은 `hsuplus-0.3.1.zip`의 압축을 풀어요. (폴더 안에 `manifest.json`이 보이면 맞아요)
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 1번 폴더 선택
4. [e클래스](https://learn.hansung.ac.kr)에 로그인 → 메인 화면 오른쪽 가장자리의 **+** 버튼
5. 처음 안내에 나오는 대로 비교과(스마트자기관리시스템)·종합정보시스템에도 로그인 → **다시 확인**

지울 때는 `chrome://extensions`에서 **삭제**를 누르면 확장이 저장한 데이터도 같이 지워져요.
(패널 아래 "연결 상태 · 설정" → **내 데이터 모두 지우기**로도 지울 수 있어요.)

## 2. 이렇게 써 보세요 (10분)
- **이번 주** 탭: 남은 강의·과제·퀴즈가 맞는지, 마감 날짜가 맞는지
- **강의실**: 과목 하나 들어가서 영상 옆 진도 막대·과제 옆 제출 표시가 맞는지
- **캘린더** 탭: 시간표가 맞는지, 월간에서 비교과·마감이 보이는지. **+ 일정**으로 일정 하나 넣어 보기
- **비교과** 탭: 신청 → "수업과 안 겹치는 것만" 눌러 보기. 내 비교과 → 포인트 숫자가 학교 화면과 같은지
- **AI** 탭: 버튼 하나 눌러 보기 (지금은 AI 서버 연결 전이라 정해진 방식으로 답해요)

## 3. 알려 주세요 (한 줄이라도 좋아요)
1. 한 줄 후기: 써 보니 어땠는지 (보고서에 이름 없이 인용해도 될지 같이 알려 주세요)
2. 틀린 것: 날짜·개수·포인트가 학교 화면과 다른 곳 (어느 탭, 무엇이)
3. 헷갈린 것: 설명 없이는 뭔지 몰랐던 화면이나 버튼
4. 있으면 좋겠는 것
5. 계속 쓸 것 같은지 (예 / 글쎄 / 아니요)

> 화면 캡처를 보내 줄 때는 이름·학번·성적이 보이지 않게 가려 주세요.
