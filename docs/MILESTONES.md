## 진행 루틴

### 개발할 때마다 (주 2~3회)
1. 이 파일에서 이번 마일스톤의 다음 항목을 고른다.
2. Claude에게 "M1 #8 하자"처럼 요청한다.
3. 받은 코드를 반영 → `chrome://extensions`에서 ON-Track 새로고침 → e클래스 새로고침 → 확인.
4. 안 되면 화면 캡처 + 콘솔(F12) 오류를 그대로 공유한다.
5. 되면 체크하고 커밋한다. 커밋 메시지 예: `M1 #8 시간표 불러오기`
6. 동작 원리를 한 줄로 설명할 수 있는지 스스로 확인한다. (본선 질의응답 대비)

### 매주 일요일 (15분)
1. 이번 주 마일스톤 완료 기준을 만족했는지 확인한다.
2. [DEVLOG.md](DEVLOG.md)에 한 일, 막힌 것, 다음 주 할 일, 캡처 1장을 남긴다.
3. 밀렸으면 5단계 기능부터 덜어내고 일정을 다시 맞춘다.

### 지켜야 할 것
- 신청·제출·저장 버튼은 코드로 누르지 않는다. (읽기 전용 원칙)
- 다른 학생의 정보에 접근하는 실험은 하지 않는다.
- API 키, 개인정보가 담긴 샘플 파일은 커밋하지 않는다. (`.gitignore` 확인)
