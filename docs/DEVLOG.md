- 막힌 것 / 해결 방법: 로그아웃해도 "연결됨"으로 나옴 → 페이지에 "로그아웃" 글자가 숨은 메뉴·스크립트에 남아 있어서였음. 판별을 3가지(로그인 화면으로 이동 여부, 비밀번호 입력칸 유무, 로그인 시에만 보이는 표식: 비교과 상단 이름(학번), 종합정보 개인시간표 메뉴)로 바꾸고 `cache: "no-store"` 추가 → 로그인/로그아웃 모두 정확히 판별
- 배운 것: 화면에 보이는 글자 하나로 상태를 판단하면 안 되고, 여러 신호를 함께 봐야 한다. 판정 근거를 로그로 남기면 원인을 빨리 찾는다.

- 결정: 설문은 하지 않음. e클래스는 매일 접속, 마감을 놓쳐 본 학생이 대부분, 익텐은 누가 알려주지 않으면 모름, 비교과는 '챙겨야 하는데' 하다가 귀찮아서 밀림 — 이미 아는 현실이라 설문으로 새로 얻을 게 없음. 근거는 익텐 사용자 수·평점, 발견 경위, M5 사용 테스트 후기로 대신함.
- 핵심 문제 정의: 학생들은 몰라서가 아니라 찾아가기 귀찮아서 밀린다 → 정보를 매일 가는 e클래스로 가져다 놓는다.
