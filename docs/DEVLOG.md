## 10/20 AI 연결 준비 (결제 전, 가짜 모델로 끝까지 확인)
- (사용자) 추천 버튼은 기본 답변 그대로(빠르고 정확, 비용 0), **직접 쓴 질문만 AI**. 모델은 틀만 두고 아주 쉽게 갈아끼우게(Gemini Flash가 싸면 그걸로, Haiku가 좋으면 그걸로)
- 모델 바꾸기 = `worker/wrangler.toml`의 `AI_PRESET` 한 줄 + 그 회사 키 등록 + 다시 배포. 확장은 그대로
  - 목록·요금·키 이름은 `worker/src/models.js` 한 곳: haiku-5.5(기본, $0.10/$0.50), gemini-3.8-flash($0.75/$3.75, 생각 토큰 포함, 2027-01부터 2배), gemini-2.5-flash-lite($0.10/$0.40, 요약 글 기준 재확인 필요), mock

  - 예비 모델(`AI_FALLBACK_PRESET`), 키 없으면 요청 안 보냄
  - 10/20 확인: 지금은 Haiku 5.5가 Gemini 3.8 Flash보다 훨씬 쌈
- 모델 비교 시험 `node worker/eval/run.mjs haiku-5.5 gemini-3.8-flash`: 가짜 학생 정보 + 고정 질문 14개(오늘·이번 주·비는 시간·포인트·설문·학사·직접 일정, 범위 밖 4개, 제목 칸 지시문 끼워 넣기)로 점수·평균 시간·질문당 비용. 키는 실행할 때 화면에 안 보이게 물어봄(저장 안 함)
- 확장: `core/config.js`의 `AI_ENDPOINT` 한 곳. background가 서버를 부름(설치별 무작위 ID, 학번과 무관). host_permissions는 늘리지 않음(서버가 확장 출처를 CORS로 허용)
  - 서버 출처 검사: 압축 해제 설치는 사람마다 확장 ID가 달라서 `chrome-extension://*` 허용(웹사이트는 막힘). 진짜 방어는 하루 한도·비용 상한
  - AI 답은 "생각하는 중…" → 문장 + 실제 항목 카드 + "AI 답변 · 날짜·마감은 학교 정보 그대로". 지어낸 번호는 버림
  - 실패하면 기본 답변 + 한 줄: 오늘 횟수 다 씀 / 너무 빠름 / 전체 사용량 많음 / 서버 연결 안 됨
