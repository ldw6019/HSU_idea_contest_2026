# 시연 모드 (README 그림·시연 영상·발표용)

실제 크롬과 실제 e클래스 화면 위에서 **학교 데이터만 가짜로** 바꿔 보여 주는 모드예요.
글꼴·배경·크기가 실제와 똑같아서, README 그림이나 시연 영상을 내 과목·과제·포인트 없이 만들 수 있어요.

## 켜고 끄기

1. e클래스에서 HSU Plus 패널 열기 → 맨 아래 **연결 상태 · 설정** 펼치기
2. **시연 모드 (가짜 데이터)** 스위치 켜기 → 페이지가 다시 열려요
3. 머리줄에 노란 **시연 모드** 표시가 보이면 켜진 거예요
4. 끌 때도 같은 스위치 → 원래 내 데이터로 돌아와요

시연 모드에서는 이렇게 동작해요.

- **학교 사이트:** 요청을 보내지 않아요. 데이터는 확장 안의 `core/demo.js`에 들어 있어요.
- **날짜:** "오늘" 기준으로 만들어져서 언제 켜도 비슷한 화면이 나와요(마감 D-1, 오늘 들을 강의 등).
- **내 설정:** 숨긴 항목, 과목 색, 직접 넣은 일정은 건드리지 않아요. 시연 중에 바꾼 건 저장되지 않아요.
- **AI 탭:** 추천 버튼은 가짜 데이터로 답해요. 직접 쓴 질문은 가짜 데이터를 AI 서버로 보내요(개인정보 없음, 하루 한도는 똑같이 써요).
- **강의실(과목 페이지):** 진도 막대 같은 강의실 표시는 실제 과목 화면에 덧붙는 기능이라 시연 모드와 상관없이 **진짜 내 과목**이 보여요. 찍을 때 주의해 주세요.

## README 그림 찍기

패널만 찍어야 해요. 뒤쪽 e클래스 화면 위쪽에 내 이름이 있으니 같이 찍히지 않게 해 주세요.

- **가장 깔끔한 방법 (크롬 개발자 도구):**
  1. F12 → 왼쪽 위 화살표로 패널 클릭
  2. 요소 패널에서 `<section class="panel">`을 오른쪽 클릭 → **Capture node screenshot**
  3. 패널 모양 그대로 PNG로 저장돼요
- **간단한 방법:** `Win + Shift + S`로 패널 영역만 잘라 찍기

`docs/images`의 파일 이름에 맞춰 바꿔 넣으면 README 그림이 바뀌어요.

## 자동 점검 (개발용)

`node tools/screenshots.mjs`를 실행하면 클라우드나 내 컴퓨터에서 시연 모드를 켜고 화면이 깨지지 않았는지 자동으로 찍어 봐요. 결과는 `tools/shots/`에 저장되고 저장소에는 올라가지 않아요. e클래스 배경을 흉내 낸 빈 화면이라 글꼴·배경이 실제와 달라서 README 그림으로는 쓰지 않아요. 시연 모드가 학교 사이트로 요청을 보내면 결과에 표시돼요.
